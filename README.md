# Wing Launch（WL）

面向新手的 Minecraft Java 版启动器（macOS 优先）。不用懂 Java、不用开终端：添加账户 → 创建实例 → 点「启动游戏」。

## 功能特性
- 🚀 一键创建实例（原版 / Forge / Fabric / Quilt / NeoForge），自动下载 Java 与游戏文件
- 🧩 模组安装（Modrinth 搜索、前置自动解析、冲突诊断与依据说明）
- 🌐 多人联机（局域网直连 + P2P 房间）、服务器一键开服与管理
- 🛡️ 崩溃自动分析（中文报告 + 一键修复）、启动前检查
- ⚡ 智能性能调优（硬件画像 + 5 套预设 + 一键回滚）
- 🧑‍🎤 皮肤库、🈶 模组 AI 翻译（术语库/翻译记忆）、🧰 工具集（种子地图/投影/配方）
- ♿ 无障碍：字号缩放、高对比度、减少动画、色盲友好、键盘全操作

## 快速开始（3 步）
1. 下载 `Wing Launch-*.dmg`，拖入「应用程序」
2. 首次打开：右键图标 →「打开」（绕过 Gatekeeper，只需一次）
3. 跟着引导：输入昵称 → 选版本 → 点「启动游戏」

## 系统要求
macOS 12+；Apple Silicon 或 Intel；建议内存 8GB+；磁盘 5GB+（首次自动下载）
